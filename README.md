# Hen Catalogue

A simple web app for browsing and managing the hens at **Hjorthagens höns**.

Built with plain HTML, CSS, and JavaScript — no backend or database.

**Live demo:** [linneaegner.github.io/hen-catalogue](https://linneaegner.github.io/hen-catalogue/)

## Features

- View hens as cards with name, breed, gender, birthdate, and ring color
- Filter by gender (all / hens / roosters)
- Book and unbook eggs per hen
- Add or remove hens
- Responsive layout with a mobile menu

## Getting started

Open `index.html` in your browser.
